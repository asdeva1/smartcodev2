## Shared frameworks (built once, Phase 1–3)

- **CSV framework** — used by modules 6, 12, 13 and employee import (see `10-csv-framework.md`).
- **State machines** — chart, production, audit, rework (`packages/shared/workflow`).
- **Scope & permission layer** — every module (see `03-rbac-matrix.md`).
- **Outbox + notifications** — every module that informs people.
- **AppShell / DataTable / CsvImportWizard / ConfirmDialog / StatusChip** — every UI.
- **Branding** — logo assets and theme (see `15-branding.md`).

## Production & audit fields (D-11 — final)

- Production form: Chart ID (from allocation, not typed), **Page Count, ICDs, DOS**, Coded Date, Remarks. **No JCD field anywhere.**
- Audit form: production values shown read-only; auditor enters **Audit Errors** and **Error Exceptions** (stored separately), Audit Date, Remarks; **Total Errors = Audit Errors + Error Exceptions**, computed by the server.
- Submitted production and completed audits are immutable; corrections create new versions/records so history and metrics stay accurate.
- CPH formula is configuration, not code.
