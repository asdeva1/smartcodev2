# @smartcode/email-templates

Reusable React Email templates. Every email uses `BrandedEmailLayout`, which shows the official SmartCode logo (absolute URL built from `BRAND_ASSET_BASE_URL`) on a light background. Activation, password-reset, audit and rework templates are added with their modules (Phase 3+). Emails never contain passwords, and tokens appear only inside the action link sent to the recipient.
